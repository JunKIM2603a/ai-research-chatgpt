# ai-research-chatgpt

AI 연구 주제 선정, 선행연구 충돌 검토, 반증 가능한 실험 계획을 관리합니다.

**2026-09-29 상태: 문헌 1차 조사·제안서 초안 작성 완료 / 주제 조건부 추천 / 지도교수 승인 및 모델 실험 전.**

이 주제 전용 프로젝트 권장 이름은 **QuantSplit — 저비트 추론의 확률·후보집합 분해**, Git 이름은 **`quant-sampling-decomposition`**입니다. 전용 저장소 이관 전까지 이 저장소에서 자료를 관리합니다. 현재 `QuantSplit 00 — 연구 정의·프로젝트 구성`을 마쳤으며, 다음은 `QuantSplit 01 — 신규성 검증·H1 확정·제안서`입니다. 제안서는 초안 상태이며 교수님 PASS 이후에 실험 단계로 진입합니다.

## 추천 후보

**저비트 추론 모델의 출력 길이 증가에서 확률 왜곡과 샘플링 후보 집합 변화의 역할 분리**

작업명: `quant-sampling-decomposition`

확률값과 top-p 후보 집합을 원본·양자화 모델 사이에서 교차 교환해, 출력 토큰 증가에 대한 개입 효과를 분리합니다. 기존 현상 재현이나 top-p 튜닝 자체를 신규성으로 주장하지 않습니다. 긍정 결과를 낙관할 직접 증거는 아직 없으며, 정밀한 부정 결과를 얻을 수 있는지도 파일럿에서 점검합니다.

## 제약과 일정

- RTX 4090 24GB ×2, RAM 128GB, CPU 18코어.
- 10/2 아이디어 제출, 교수 승인 후 실험 시작.
- 10/12 초기 핵심 결과, 11/20 주요 실험 종료, 12/14 논문 및 최종심사 목표.
- 실측 처리량·검정력이 부족하면 10/12 확정 결과를 약속하지 않습니다.

## 기록 원칙

1. 문헌 보고값, 제안 가설, 실제 결과, 자원 추정을 구분합니다.
2. p>0.05를 동등성이나 실패 원인의 증거로 쓰지 않습니다.
3. 최초성·가설 지지·논문 게재를 보장하지 않습니다.
4. 확증 전 설정을 동결하고 변경 사유를 남깁니다.
5. 논문 본문·모델 가중치·대용량 원시 로그는 복사해 올리지 않습니다.
