# ai-research-chatgpt

AI 연구 주제 선정과 가설 검증 계획을 관리하는 저장소입니다.

## 현재 상태 — 2026-09-29 (KST)

- 문헌 기반 후보 검토 진행 중. 최종 주제 확정 및 지도교수 승인은 아직 없습니다.
- 연구 실험은 실행하지 않았습니다. 승인 전에는 조사와 실험 설계만 진행합니다.
- 목표: 10/2 아이디어 제출, 10/12 초기 핵심 결과, 11/20 주요 실험 종료, 12/14 논문 및 최종심사.
- 자원: RTX 4090 24GB ×2, RAM 128GB, CPU 18코어.

## 선정 원칙

1. 이미 보고된 현상을 H1의 참신성으로 주장하지 않습니다.
2. 1차 문헌에서 확인한 사실, 미검증 가설, 자원 추정을 구분합니다.
3. 유의하지 않은 결과를 동등성이나 실패의 원인으로 해석하지 않습니다.
4. 가설이 지지되지 않아도 효과의 상한 또는 경쟁 설명을 식별할 수 있는 설계를 우선합니다.
5. 논문 게재나 가설 성공을 보장하지 않습니다.

조사 보고서, 선행연구 대조표, 실험 계획, 의사결정 기록을 순차적으로 추가합니다.
